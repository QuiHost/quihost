# QuiHost

QuiHost è una piattaforma all-in-one per host di case vacanza e addetti alle pulizie.

## Versione Aggiornata

Questa versione include:
- Correzioni errori nella pagina di registrazione
- Correzioni errori nell'API del profilo utente
- Migliorata gestione degli errori e dell'interfaccia utente

## Sviluppo

Per avviare l'ambiente di sviluppo:

```bash
npm install
npm run dev
```

## Build

Per creare una build di produzione:

```bash
npm run build
```
